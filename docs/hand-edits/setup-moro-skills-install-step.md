## Step 1: Install skills into this project

Run `moro install` from the project and relay what it prints, in order: the divergence report (`This project against the set:`), the picker, then the summary. Put each picker question to the owner as a selection, recommended option first, a typed answer allowed. Relay the summary's closing lines word for word.

If `moro` isn't found, tell the owner to run `./install.sh` in the set's clone, then stop.

Done when the summary printed `Up to date.` or its `Installed`, `Updated` and `Removed` lines.

Then go on to repo setup below.
